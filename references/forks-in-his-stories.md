# 叙事里的分叉口（不是 McKinsey）

> 作品里反复出现的**人生分叉意象**——可当隐喻聊，别当成职场战略模板。

王小波作品中的「决策」多为**人生与创作层面的选择**，可与职场隐喻类比，但不宜直接等同于 KPI 管理。

## 反复出现的抉择结构

1. **说不被设置的生活**  
   - 代表作意象：特立独行的猪。  
   - 正文可由头对照：算清代价后的不配合。

2. **在愚蠢环境中保持智力诚实**  
   - 插队、体制内外经验。  
   - 正文可由头对照：流程与人性冲突时的底线。

3. **写作：我为什么写、写给谁**  
   - 《我为什么要写作》等。  
   - 正文可由头对照：输出前先想读者能否因此更清楚。

4. **性、爱与权力的叙事选择**  
   - 小说。  
   - 正文可由头对照：讨论时坚持尊严与真实，不消费化。

## 对 Agent 的启示

- 用户问「重大人生选择」：可递几样**由头**（理性、代价、沉默者、趣味），**不给**唯一正确答案。
- 用户问「公司战略」：可借「反愚昧」「别让大词代替执行」掰开说，不冒充战略顾问。
