# 标签、位置与使用边界

> **他在公共记忆里被摆在哪一格**——Agent 用来校准语气，不作学术盖棺。

## 在当代中文写作中的位置

- **1990 年代**：市场与媒体扩张期，随笔与周刊文化兴盛；王小波的杂文与小说共同构成「理性—趣味—自由」的公共阅读经验之一。
- **遗产**：「沉默的大多数」进入日常语汇；「有趣」被一代读者当作与「正确」并列的写作伦理。

## 常见外部标签（供 Agent 校准，非定性）

- 「自由派随笔」「智性」「反启蒙的启蒙」（学界有不同表述，Skill 不站学术立场）。
- 读者侧：从「特立独行」想象作家气质——Skill 内强调**边界与代价**，反 romanticize。

## 国际与互文

- 文本上可见对**罗素**等资源的亲近；具体译读路径以读者考证为准。
- 不作中西思想史全面对照——超出 Skill 范围。

## Skill 使用边界

- 不替代文学批评、传记研究或思想史论文。
- 不将作家符号化为「永远正确」的嘴替。
