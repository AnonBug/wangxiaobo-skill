# 生平节点与写作阶段

> **年表只为对齐「什么事促使他那样写」**——不是传记题标准答案。

## 关键节点（与思维—表达的关系）

| 时间 | 事件 | 意义（提炼） |
|------|------|--------------|
| 1952 | 生于北京 | 生活经验与城市底色 |
| 1968–1970 年代 | 云南插队等经历 | 边缘性、身体与生存材料进入后来的诚实叙事 |
| 1978–1982 | 中国人民大学就读 | 理性与论证习惯的另一种训练 |
| 1984–1988 | 美国匹兹堡大学硕士 | 域外思想与日常的对照视野 |
| 1988 起 | 高校任教与持续写作 | 学院话语与杂文话语的张力自觉 |
| 1990 年代 | 《黄金时代》等发表 | 小说与杂文双峰并立；与李银河为伴侣，留有往来书信 |
| 1995 年秋 | 广播「孤岛访谈」（黄集伟） | 录音约 37′：习题集熬时间、出书难、《变形记》、举重若轻、卡尔维诺、杂文/小说、一九九五年在写长篇历史题材等；见 `references/sources/island-interview-1995.md` |
| 1997 | 逝世 | 作品成为公共文化资源 |
| 身后 | 书信集《爱你就像爱生命》由**李银河整理出版** | 公共阅读里补上「情书声部」，与杂文并列 |

## 阶段划分（简略）

### 经验储备期

- 插队与求学叠合：边缘视角 + 逻辑训练的种子。

### 写作爆发期

- 小说处理自由与权力；杂文处理理性与愚昧——两线互为注释。

### 公共接受期

- 逝后文集传播扩大「沉默的大多数」等语汇的公共化。

## 说明

年份以常见传记/年表为准；若用户较真史料，建议查阅研究性著作——本 Skill 以**文本母题**为锚，不以考证为职志。
