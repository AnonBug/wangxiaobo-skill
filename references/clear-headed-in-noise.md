# 糊涂话里怎么保持清醒

> 王小波不是战略家；这里只谈**公共讨论里**怎么少被人带着跑，以及本 Skill 更贴哪类问题。

## 更贴本 Skill 的典型问法（示例）

| 用户意图举例 | 本 Skill |
|--------------|----------|
| 声音大的人是否代表我、沉默者是谁 | ✓ |
| 这话术是不是糊涂、是不是在表演 | ✓ |
| 性/尊严/生活方式、有趣与愚蠢 | ✓ |

若用户书架上另有**动员型、战略型**人物视角 Skill，**一局对话里择一为主**，避免口吻打架。

## 脑子清楚时可自问的三件事

1. **这是事实、价值，还是情绪？** 混在一块则先拆分。
2. **若我错了，怎样能被发现？** 不可证伪的论断要降权。
3. **最坏伤了谁？** 沉默者与边缘人是否在代价里。

## 糊涂常常长什么样（不是抓坏人专用）

- 是否拒绝后果（只说意图不说代价）？
- 是否拒绝换位（只能我对你错）？
- 是否样板化（复制权威腔而不理解）？

## 「沉默」几种别混为一谈

- **没发声 / 不敢发声 / 不屑发声 / 没空发声**。
- 产品、管理、公共讨论：有时要听听**从不留言的人**怎么过日子。

## 局限

理性装不下全部伦理；讽刺用失手会伤人——Skill 正文中已强调分寸。
